# 推甄戰備室

管院五科（管理學、經濟學、統計學、行銷管理、財務管理）的學習與題庫 App，為研究所推甄面試而做。

教材採雙層設計：**面試層**是 30 秒能講出口的版本，**進階層**含模型細節、限制與學術爭論，銜接研究所課程。讀完之後用四種模式複習：名詞閃卡、選擇題、申論自評、面試模擬。

純前端 PWA，**零外部依賴、離線完整可用**，資料只存在自己的裝置上。

---

## 怎麼打開

```bash
python serve.py
```

會自動開瀏覽器到 `http://localhost:8770`。按 Ctrl+C 停止。

想直接雙擊 `index.html` 也可以看，但**建議用 serve.py**——用 `file://` 開的話 Service Worker 不會運作，就沒有離線功能。

### 放到手機上

之後推到 GitHub Pages 後，用手機瀏覽器打開網址 →「加到主畫面」，就會像一般 App 一樣有圖示、可全螢幕、**沒網路也能刷題**。通勤、排隊的零碎時間是這 67 天最關鍵的資源。

## 四個分頁

### 今天
打開就知道今天要做什麼。上方是倒數天數與整體進度，下面四張任務卡分別是閃卡、選擇題、申論、面試模擬，點下去直接開始。

每日目標的算法是：**今天到期的複習量 ＋ 今天該碰的新東西**。「該碰的新東西」是把還沒學過的數量平攤到剩餘天數，所以剩越少天、每天要碰的越多。這個壓力是真的，不會被藏起來。

### 讀
科目 → 章節 → 知識點。每個知識點分兩層：

- **面試層**：30 秒能講出口的版本，預設展開
- **進階層**：模型細節、限制、學術爭論，收合起來，銜接研究所課程時再讀

底部可以「標記重點」（之後能只練標記的）、「標記讀完」（算進度），或直接跳去練這一節。

### 練
先選範圍（科目／章節／只練錯題／只練標記／只練必考），再選四種模式之一：

| 模式 | 做什麼 |
|---|---|
| **名詞閃卡** | 正面名詞、背面定義。**先在心裡講一遍再翻面**——直接看答案等於沒練到。翻面後四級自評，系統排下次複習時間 |
| **選擇題** | 立即對答案＋詳解。答錯自動進錯題本，要**連續答對 2 次**才移出 |
| **申論自評** | 先自己寫（或至少在腦中列點），再展開答題大綱逐點打勾，由勾選數建議分數 |
| **面試模擬** | 抽題 → 60 秒計時**出聲**作答 → 講完看答題框架與常見地雷 |

### 我
統計、近 7 天練習量、各科進度、素材庫、各校側重、字體大小、設定、匯出匯入。

## 字體大小

右上角的 **Aa** 按鈕（或「我 → 字體大小」）可以切五段：**小 / 標準 / 大 / 特大 / 最大**。

按下去**立刻生效並存檔**，不用再按確定——把電腦推遠了才在調，需要當場看夠不夠大。面板下方有一段真實教材當預覽。

整個 App 的字都會跟著變，包含教材內文、題目與選項。桌機上文字放大時，內容欄位也會跟著加寬，所以不會變成「大字擠在窄欄裡」。設定會記住，下次打開直接就是你調好的大小。

## 兩個為你的情況特別調整的地方

### 1. 複習間隔上限 21 天

標準的間隔複習演算法會把熟題排到幾個月後複習。但你的目標日在三個月內，排到考後才複習等於沒複習。所以間隔上限壓在 **21 天**，而且**永遠不會超過距離目標日的天數**——保證每個知識點在面試前至少還會再滾過一輪。

### 2. 考前 14 天自動進入衝刺模式

倒數進入 14 天內時，App 會自己切換：忽略複習排程，改成優先出**錯題 → 標記 → 必考**，全部刷過。介面會轉成紅色提醒你。這個天數可以在設定裡改。

## 「我的素材庫」——面試前一定要先做這件事

教授最常追問的是「**可以舉個例子嗎**」。答不出來通常不是不懂理論，而是沒有事先把自己的經歷跟理論掛勾。

專題、side project、實習、社團、打工都是素材，但它們在面試現場不會自動變成答案——**要先寫下來，並標好可以扣哪個理論**。

在「我 → 我的素材庫」把每則素材照這個格式寫：

```
情境    ：當時的問題或背景
我做了什麼：你的具體行動（不是團隊的）
結果    ：有數字最好，沒有就講具體變化
扣什麼理論：例如「顧客痛點洞察」「利基定位」「MVP 與精實創業」
```

面試模擬抽到舉例類題目時，側欄會把素材列出來提醒你。

## 67 天讀書排程建議

以 2026-08-09 起算、目標日 2026-10-15。

| 期間 | 天數 | 重點 |
|---|---|---|
| **第 1–2 週**（8/09–8/22） | 14 | 把行銷第 1、5 章與管理第 1 章讀完面試層，每天刷閃卡建立排程。**同時把素材庫寫完**——這件事越早做越好，因為書審資料也用得到 |
| **第 3–5 週**（8/23–9/12） | 21 | 讀完現有六章的面試層＋進階層，選擇題全部刷過一輪，錯題本開始累積 |
| **第 6–8 週**（9/13–10/03） | 21 | 補上新增的章節；申論每天一題不能斷（這是最容易偷懶但最拉開差距的部分）；面試模擬每天一題出聲練 |
| **第 9 週起**（10/04–） | 12 | App 自動進入衝刺模式。**不要再開新章節**，把錯題本清乾淨、必考題講順、各校側重掃過 |

實務提醒：申論與面試模擬每天各一題看起來很少，但**這兩項是唯一會逼你產出的練習**，選擇題刷得再多也取代不了。真的沒時間時，寧可砍選擇題也不要砍這兩項。

兩個閱讀上的小設計：

- 教材內文中的**淡色底線詞**是跨章連結，點一下會直接跳到那個知識點——**而且是跨科的**。經濟學的彈性會連到行銷的訂價，管理學的激勵會連到經濟學的誘因設計。申論要拉開分數，靠的就是把不同章節、不同科目串起來。
- 經濟學與統計學的算式（例如 `Ed = (ΔQ/Q) ÷ (ΔP/P)`、`z = (x̄ − μ) / (σ/√n)`）會用**等寬字體加淡底**顯示，讓公式從中文段落裡跳出來，不會跟內文混在一起。

### 統計學的計算題長什麼樣

統計學是第一科有**計算題**的。答錯時的詳解會**一步一步列出算式**，而不是只給一句結論。例如問到「盛行率 1% 的疾病、準確率 99% 的檢測，驗出陽性有多大機率真的生病」，詳解會用一萬人推一次：有病 100 人驗出 99 人、無病 9,900 人誤報 495 人、所以陽性共 594 人中只有 99 人真的有病，約 16.7%。

**這類題目答案本身就是面試素材**——能當場算給教授看，比背定義有用得多。

### 之後要補的

程式功能已經完整，**接下來的重點全在教材**。

**統計學十章已全部完成。** 原本卡住這一科的兩個問題都已解決：計算過程直接寫在詳解裡（不需要新欄位），公式用 Unicode 的上下標配等寬字體（`x̄`、`σ²`、`√`、`Σ`、`H₀`）已足夠讀，不必引入外部套件。

**第 4–10 章是研究方法的主幹**，也是台大商研口試最愛追問的範圍：信賴區間到底該怎麼解讀、p 值不顯著代表什麼、型一型二誤差哪個嚴重、相關為什麼不等於因果、控制變數是不是越多越好、隨機抽樣跟隨機分派差在哪。最後一章更直接處理「怎麼質疑一個數字」——生存者偏誤、圖表誤導、相對風險與絕對風險的差別。這些題目在「面試模擬」分頁都有對應的答題框架與地雷提醒。

**財務管理已開檔，完成第 1–4 章**（貨幣的時間價值、風險與報酬、資本資產定價與效率市場、債券評價）。開工前先試寫第 1 章確認過排版：年金公式 `PVA = PMT × [1 − (1+r)⁻ⁿ] / r` 這種巢狀最深的式子在手機大字級下仍然可讀，**所以財管沿用統計學的作法，同樣不需要外部套件**。

剩下財管的第 8–10 章（股利政策 → 營運資金管理 → 財務報表分析）。其中**資本預算與資本結構是財管的核心**，也是口試最常追問的兩章。

要補內容時，直接說「**下一章**」就好，程式碼不用動。想跳過順序也可以，直接講要哪一章或哪一科。

### 已知還可以再加強的

這些都不影響現在使用，但值得知道：

- **看不到自己反覆錯在哪**。目前只能「練錯題」，沒有一個畫面列出你最常錯的知識點——而那其實是最有用的訊號。
- **申論寫過的答案存了但看不到**。同一題寫第二次時，沒辦法對照上次寫了什麼。
- **教材沒有圖**。BCG 矩陣、定位圖、PLC 曲線、供需圖這類本來是圖的東西，目前全是文字描述。經濟學開了之後這一項的影響更明顯——供需曲線的移動用文字說明，理解成本確實比看圖高。
- **桌機沒有鍵盤快捷鍵**。刷卡只能用滑鼠點，比較慢。
- **教材尚未寫完**。財管還有三章（股利政策、營運資金管理、財務報表分析），其餘四科都已十章完成。

## 資料存在哪

全部在瀏覽器的 localStorage，**只存在這台裝置上**，沒有帳號也沒有後端。

所以：

- 換裝置或重灌前，**先去「我 → 匯出備份」存一份 JSON**
- 清瀏覽器資料會一併清掉進度
- 手機和電腦的進度不會同步（要同步就靠匯出匯入）

匯入時會**整包置換**目前的進度，不是合併。App 會擋掉不是它匯出的檔案，避免選錯檔案就把進度洗掉。
